# Trackl – TCG Scan & Collection Manager

**Scan it. Find it. Track it.**

Trackl is a modern, minimalist TCG collection manager for mobile devices, built for collectors who want fast card identification, precise search tools, and a clean collection workflow.

## Key Features

### Scan by Set & Card Code

Unlike many scanners that mainly rely on full card image recognition, Trackl is designed to identify cards using their printed set and card codes.

This makes scanning fast, practical, and highly accurate for real collecting workflows.

### Powerful Smart Search

Trackl supports precise search patterns that match the way collectors identify cards.

| Search type | Example | Description |
|---|---|---|
| Card name | `name` | Search by card name |
| Collector number | `123/123` | Search using the printed card number |
| Compact number | `123123` | Search without the slash |
| Set and number | `set/123` | Combine a set identifier and card number |
| Compact set search | `set123` | Search without a separator |

### Collection Management

- Track multiple variants of the same card
- Manage foil types and illustration variants
- Record language, condition, and special coatings
- Organize and filter your collection

### Market Price Information

Trackl provides available market price estimates for supported cards and variants.

Prices depend on external data sources and may not be available for every card or variant.
